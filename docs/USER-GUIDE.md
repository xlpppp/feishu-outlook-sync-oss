# 用户使用指引

本服务可按你选择的方向，在**飞书**与你自己的 **Outlook.com / 个人 Microsoft 日历**之间同步日程。  
每位同事各自授权，互不影响；数据只会写入**你自己**的日历。

---

## 你需要准备

1. 管理员给你的同步网站地址（例如 `https://sync.example.com`）
2. 你的**飞书**账号
3. 你的**个人 Microsoft / Outlook.com** 账号（不是公司 Office 365 也没关系；按管理员配置为准）

---

## 第一次使用

1. 用浏览器打开同步网站  
2. 点击 **「连接 Outlook」**  
   - 登录你的个人 Microsoft 账户  
   - 同意日历读写等权限  
3. 点击 **「连接飞书」**  
   - 登录飞书并同意日历读/写权限（写权限在「Outlook→飞书」或「双向」时需要）  
4. 在 **「同步方向」** 中选择其一并点 **保存**：
   - **飞书 → Outlook**（默认）：飞书主日历 → Outlook「Feishu Sync」
   - **Outlook → 飞书**：Outlook 默认日历 → 飞书「Outlook Sync」
   - **双向**：两腿都执行（各自写到专用目标日历，不会回环）
5. 两端都显示「已连接」后，点击 **「立即同步」**  
6. 在 Outlook / 飞书中打开对应目标日历查看结果

之后后台会按管理员设定的间隔（例如每 3–15 分钟）自动同步。若管理员开启了**推送同步**，你在飞书/Outlook **源日历**改日程后，通常几十秒内就会触发一次同步，无需等满整个间隔。也可随时再点「立即同步」。

---

## 日常注意

- **防回环**：服务不会从目标日历反向拉取。请勿指望在「Feishu Sync」或「Outlook Sync」里改日程再同步回去。  
- **请在源日历中修改**真正的日程（飞书主日历或 Outlook 默认日历，取决于方向）。  
- **飞书「订阅」日历默认不同步到 Outlook**（同事公开日历等）；仅同步你的主日历。管理员可用环境变量调整。  
- 默认同步「最近几天 + 未来约两个月」窗口内的日程（具体天数由管理员配置）。  
- 若你选择了需要写入飞书的方向，但飞书是很早以前用「只读」连上的，请先 **断开飞书** 再重新连接以获取写权限。  
- 若很久没同步成功，页面上的「最近同步」会显示错误信息；常见原因是授权过期——重新点「连接」即可。

---

## 断开授权

- **断开飞书** / **断开 Outlook**：删除本服务保存的令牌，停止代你访问该平台。  
- **退出会话**：仅清除本站登录 Cookie，不一定删除已保存的授权（取决于是否同时点了断开）。  
- 若不再使用本服务，建议两端都「断开」，并在飞书/微软账户安全页撤销应用授权。

---

## 隐私简述

- 访问令牌在服务器上**加密存储**。  
- 同步内容仅写入你授权的日历。  
- 如有疑问，请联系部署本服务的管理员。
